Gemini 模仿菜練習：AI OCR Classroom

這是給同學與 Gemini / Canva 類工具看的練習入口。這頁只提供任務、規格與限制，不直接提供完整答案。

教學重點：只有題目，和「題目 + 附加說明」，AI 產出的品質會不同。本練習刻意把答案與說明分開，避免 AI 一開始直接讀到完整實作。

練習任務

請做一個單檔 HTML 的教室座位 SVG 工具，讓老師可以管理固定長桌、學生座位、姓名、性別與匯入匯出資料。

  • 教室有 3 排 x 2 張長桌。
  • 每張長桌有 3 個學生座位，總共 18 個學生座位。
  • 老師在前方老師區，可以在老師區域內移動。
  • 學生只能吸附到固定座位。
  • 拖到已有人的座位時，兩位學生交換座位。

畫面目標

必要功能

  1. 用 SVG 畫固定桌子、座位、老師區與人物卡。
  2. 姓名空白時，人物卡不顯示，但座位仍存在。
  3. 學生可選男 / 女，小圓點用不同顏色表示。
  4. 老師小圓點固定綠色，不受男女選項影響。
  5. 支援 JSON / Excel 匯出匯入，匯入時全覆蓋。
  6. 工程模式案件要用學生視角，在圖上浮出 SVG 註解。

範例團體治理

新增一個「案例：載入範例團體」功能。

  • 範例團體是 8 位英文名學生。
  • 男生 4 位、女生 4 位。
  • 載入前需要密碼。
  • 這是靜態頁面的教學級治理示範，不是後端權限控管。

附加說明

同學可以先只用本頁練習，再加入附加說明比較 AI 產出的差異。附加說明有 HTML 版與 Markdown 版，兩者內容對應。
