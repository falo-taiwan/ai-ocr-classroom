AI OCR Classroom Gemini 模仿菜練習與附加說明

這份 HTML 是人看的整合參考檔：前半是練習題，後半是附加說明。它不包含完整答案，避免 Gemini / Canva 一開始直接看到實作。

教學重點：只有題目，和「題目 + 附加說明」，AI 產出的品質會不同。這份檔案用來示範附加說明如何幫助 AI 理解架構、資料表與治理邊界。

練習任務

請做一個單檔 HTML 的教室座位 SVG 工具，讓老師可以管理固定長桌、學生座位、姓名、性別與匯入匯出資料。

  • 教室有 3 排 x 2 張長桌。
  • 每張長桌有 3 個學生座位，總共 18 個學生座位。
  • 老師在前方老師區，可以在老師區域內移動。
  • 學生只能吸附到固定座位。
  • 拖到已有人的座位時，兩位學生交換座位。

畫面目標

必要功能

  1. 用 SVG 畫固定桌子、座位、老師區與人物卡。
  2. 姓名空白時，人物卡不顯示，但座位仍存在。
  3. 學生可選男 / 女，小圓點用不同顏色表示。
  4. 老師小圓點固定綠色，不受男女選項影響。
  5. 支援 JSON / Excel 匯出匯入，匯入時全覆蓋。
  6. 工程模式案件要用學生視角，在圖上浮出 SVG 註解。

範例團體治理

新增一個「案例：載入範例團體」功能。

  • 範例團體是 8 位英文名學生。
  • 男生 4 位、女生 4 位。
  • 載入前需要密碼 20260522。
  • 這是靜態頁面的教學級治理示範，不是後端權限控管。

座標系

老師使用圖形座標系，記錄 x / y，只能在老師區域內移動。學生使用座位絕對座標系，記錄 seatId，只能吸附學生座位。

人物規則

  • 姓名空白時，人物卡不顯示。
  • 學生可選男 / 女，小圓點依性別變色。
  • 老師小圓點固定綠色，不受男女欄位影響。
  • 學生拖到已有人的座位時，兩位學生交換 seatId。

資料表設計

Sheet用途
people人物資料：姓名、角色、性別、色卡、座位或自由座標
seats座位資料：固定桌位與座位座標
colors色卡資料：OCR 用 RGB 色彩基準
rules工程規則：角色邊界、座標系、匯入規則
views視角定義：老師視角與學生視角

工程模式

工程模式以學生視角為標準座標。使用者點一個案件後，系統應在座位 SVG 上浮出註解圖層，說明目前規則。
