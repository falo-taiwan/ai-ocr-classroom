# AI OCR Classroom v1.02 說明

## 這是什麼

這是一個單檔 HTML 的教室座位 SVG 工具，用來教初學者理解：

- SVG 畫面配置
- 老師圖形座標系
- 學生固定座位座標系
- 男女性別標記
- 工程模式註解圖層
- JSON / Excel 匯入匯出閉環
- 靜態頁面的治理門檻

## v1.02 重點

- 預設範例團體改成英文名字。
- 預設只載入 8 位學生：4 男、4 女。
- 性別會自動帶入，小圓點依性別顯示不同顏色。
- 老師仍是 `Force`，老師小圓點固定綠色，不受男女選項影響。
- 新增「案例：載入範例團體」。
- 載入範例團體需要密碼。

## 範例團體治理

範例團體載入密碼是 `20260522`。

在 GitHub Pages 這種靜態網站中，這個密碼門檻是教學級治理示範，不是後端權限控管。程式使用瀏覽器 Web Crypto 做 SHA-256 雜湊比對，目的是讓學生理解：

- 範例資料不應該無條件載入
- 人名與座位資料要有治理邊界
- 載入資料是一個授權動作
- 匯入後會全覆蓋目前資料

## 資料表設計

匯出 JSON / Excel 時，資料會以資料庫概念整理：

| Sheet | 用途 |
|---|---|
| people | 人物資料：姓名、角色、性別、色卡、座位或自由座標 |
| seats | 座位資料：固定桌位與座位座標 |
| colors | 色卡資料：OCR 用 RGB 色彩基準 |
| rules | 工程規則：角色邊界、座標系、匯入規則 |
| views | 視角定義：老師視角與學生視角 |

## 座標系

老師使用圖形座標系：

- 記錄 `x / y`
- 只能在老師區域內移動
- 不吸附學生座位

學生使用座位絕對座標系：

- 記錄 `seatId`
- 桌子與座位不可移動
- 拖到已有人的座位時，兩人交換位置

## 工程模式

工程模式以學生視角作為標準座標。點選案件後，系統會自動切到學生視角，再在座位 SVG 上浮出註解圖層。

這樣可以避免老師列印視角與工程標定視角混淆。
